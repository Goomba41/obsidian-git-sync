# Описание

Блокировать элементы интерфейса в зависимости от статуса загрузки. Два вида блокировщиков: локальный и глобальный.
Глобальным отслеживать статус http клиента, локальный может дробиться на разные части по элементам страницы: поле поиска, тело календаря, заголовок календаря и т.п.
