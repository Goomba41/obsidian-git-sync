## Базовая информация

Любой [[API]] следует ресурсно-ориентированному дизайну и состоит из трех концепций:

- **ресурс** - часть данных (например, User)
- **коллекция** - группа ресурсов (например, []User) ^ceef4f
- **[[URL]]** или **маршрут** - местоположение ресурса или коллекции (например, /users или /user/{:id}) ^e9aed5
