Хранилище Obsidian для хранения заметок и создания базы знаний

Структура папок:
1. [GTD](https://habr.com/ru/articles/743628/) - отслеживание проектов по методологии [Getting Things Done](https://ru.wikipedia.org/wiki/Getting_Things_Done) (GTD) Дэвида Аллена.
2. Logbook - журнал событий
3. Wiki - база знаний
4. Templates - шаблоны заметок
