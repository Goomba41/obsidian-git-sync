## Создание самоподписанного сертификата для nginx

Корневые сертификаты уже созданы сроком на 10 лет, при необходимости перегенерить сертификат на веб-сервер. Конфиг уже создан, при необходимости добавить новые SAN. ВНИМАНИЕ, при добавлении нового SAN [нельзя делать wildcard для TLD](https://serverfault.com/a/675233), поэтому указывать поддомены напрямую.

Генерация ключа для CA
```openssl genrsa -out selfsignCA.key 4096```

Генерация сертификата CA
```openssl req -new -x509 -days 3650 -key selfsignCA.key -out selfsignCA.crt```

Генерация ключа для сервера
```openssl genrsa -out somedomain.key 2048```

Создать файл конфигурации с содержимым:
```
[req]
default_bits       = 2048
default_md	   = sha256
default_keyfile    = nahodka-kso.ksp43.ru.key
distinguished_name = req_distinguished_name
req_extensions     = req_ext
x509_extensions    = v3_ca

[req_distinguished_name]
countryName                 = RU
countryName_default         = RU
stateOrProvinceName         = Область
stateOrProvinceName_default = Kirov Oblast
localityName                = Город
localityName_default        = Kirov
organizationName            = Организация
organizationName_default    = Nahodka-AIS
organizationalUnitName      = Отдел
organizationalUnitName_default = KSO
commonName                  = CN
commonName_default          = nahodka-kso.ksp43.ru
commonName_max              = 64

[req_ext]
keyUsage=critical,digitalSignature,keyEncipherment
extendedKeyUsage=critical,serverAuth,clientAuth
subjectAltName = @alt_names

[v3_ca]
subjectAltName = @alt_names

[alt_names]
IP.1	= 91.223.244.77
DNS.1	= nahodka-kso.ksp43.ru
```

Создание запроса (внимание на указание файла конфигурации)
```openssl req -new -nodes -key somedomain.key -config openssl.cnf -out somedomain.csr```

Проверка сертификата в запросе (внимание на SAN)
```openssl req -noout -text -in somedomain.csr```

Подписание и выпуск сертификата на сервер
```openssl x509 -req -in somedomain.csr -CA selfsignCA.crt -CAkey selfsignCA.key -CAcreateserial -out somedomain.crt -days 1024 -sha256 -extfile openssl.cnf -extensions req_ext```
