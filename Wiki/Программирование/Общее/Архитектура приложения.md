## Объяснение структуры

### Themes

#### **TypeScript конфигурация (themes/*.ts)**

**Назначение:**

- Программный доступ в composable (`useTheme`)
- Типизация цветов
- ️ **НЕ используется** для генерации CSS напрямую

``` typescript
const { brandColors } = useTheme()
console.log(brandColors.value.primary[500]) // '#0ea5e9'
```

#### **2. CSS файлы тем (themes/brand/blue.css)**

**Назначение:**

- Динамическое переключение тем через классы
- CSS переменные для использования в стилях
- Работает без пересборки приложения

``` typescript
// При смене темы
document.documentElement.classList.add('theme-blue')
// → Автоматически применяются все переменные из blue.css
```

### Composables

#### **Общая структура папки**

|Категория|Примеры|Когда использовать|Где хранить состояние|
|---|---|---|---|
|**app/**|useTheme, useAuth, useLocale|Глобальное состояние приложения|Глобально (useState, useCookie)|
|**features/**|useProjects, useTasks, useUsers|Бизнес-логика конкретной фичи|В сторе или локально|
|**shared/**|useDebounce, useClickOutside, useApi|Универсальные утилиты|Локально или без состояния|

``` typescript
composables/
├── app/                          # Глобальное состояние приложения
│   ├── useTheme.ts              # Тема приложения
│   ├── useAuth.ts               # Глобальная аутентификация
│   ├── useLocale.ts             # Локализация
│   ├── useLayout.ts             # Состояние лейаута
│   ├── useNotifications.ts      # Уведомления
│   ├── useApp.ts                # Общее состояние
│   └── useConfig.ts             # Конфигурация
│
├── features/                     # Бизнес-логика фич
│   ├── auth/
│   │   ├── useAuth.ts           # Логика аутентификации
│   │   └── useAuthStore.ts      # Состояние аутентификации
│   ├── project/
│   │   ├── useProjects.ts       # Логика проектов
│   │   ├── useProjectStore.ts   # Состояние проектов
│   │   └── useProjectForm.ts    # Форма проекта
│   ├── task/
│   │   ├── useTasks.ts          # Логика задач
│   │   ├── useTaskStore.ts      # Состояние задач
│   │   └── useTaskForm.ts       # Форма задачи
│   ├── user/
│   │   ├── useUsers.ts          # Логика пользователей
│   │   └── useUserStore.ts      # Состояние пользователей
│   ├── settings/
│   │   ├── useSettings.ts       # Логика настроек
│   │   └── useSettingsStore.ts  # Состояние настроек
│   └── search/
│       ├── useSearch.ts         # Логика поиска
│       └── useSearchFilters.ts  # Фильтры поиска
│
└── shared/                       # Утилитарные функции
    ├── useApi.ts                # API клиент
    ├── useValidation.ts         # Валидация
    ├── useCache.ts              # Кэширование
    ├── useOffline.ts            # Офлайн-режим
    ├── useLocalStorage.ts       # localStorage
    ├── useSessionStorage.ts     # sessionStorage
    ├── useDebounce.ts           # Debounce
    ├── useThrottle.ts           # Throttle
    ├── useClickOutside.ts       # Клик вне
    ├── useMediaQuery.ts         # Медиа запросы
    ├── useIntersectionObserver.ts # Intersection Observer
    ├── useScroll.ts             # Скролл
    ├── useCopyToClipboard.ts    # Копирование
    ├── useDownloadFile.ts       # Скачивание
    ├── useFileUpload.ts         # Загрузка файлов
    ├── usePrint.ts              # Печать
    └── useGeolocation.ts        # Геолокация
```

#### **1. app/ - Глобальное состояние приложения**

**Что здесь размещать:** Composables, которые управляют **глобальным состоянием всего приложения**, доступны **всем компонентам** и не привязаны к конкретной фиче.

``` typescript
composables/
└── app/
    ├── useTheme.ts          # ⭐ Управление темой приложения
    ├── useAuth.ts           # Глобальная аутентификация
    ├── useApp.ts            # Общее состояние приложения
    ├── useConfig.ts         # Конфигурация приложения
    ├── useLayout.ts         # Состояние лейаута (сайдбар, хедер)
    ├── useLocale.ts         # Локализация (i18n)
    ├── useNotifications.ts  # Уведомления приложения
    ├── useDarkMode.ts       # Темный режим (если отдельно от темы)
    └── usePreferences.ts    # Пользовательские настройки
```

#### **2. features/ - Бизнес-логика конкретных фич**
 
**Что здесь размещать:** Composables, которые реализуют **конкретную бизнес-логику** или **управление данными** для определенной фичи/модуля.

``` typescript
composables/
└── features/
    ├── auth/
    │   ├── useAuth.ts           # Логика аутентификации
    │   └── useAuthStore.ts      # Состояние аутентификации
    ├── project/
    │   ├── useProjects.ts       # Логика управления проектами
    │   ├── useProjectStore.ts   # Состояние проектов
    │   └── useProjectForm.ts    # Логика формы проекта
    ├── task/
    │   ├── useTasks.ts          # Логика управления задачами
    │   ├── useTaskStore.ts      # Состояние задач
    │   └── useTaskForm.ts       # Логика формы задачи
    ├── user/
    │   ├── useUsers.ts          # Логика управления пользователями
    │   └── useUserStore.ts      # Состояние пользователей
    ├── settings/
    │   ├── useSettings.ts       # Логика настроек
    │   └── useSettingsStore.ts  # Состояние настроек
    └── search/
        ├── useSearch.ts         # Логика поиска
        └── useSearchFilters.ts  # Фильтры поиска
```

#### **3. shared/ - Утилитарные функции**

**Что здесь размещать:** **Универсальные утилиты**, которые **не имеют состояния** или имеют **локальное состояние**, могут использоваться **в любом месте** приложения.

``` typescript
composables/
└── shared/
    ├── useApi.ts                # API клиент
    ├── useValidation.ts         # Валидация форм
    ├── useCache.ts              # Кэширование данных
    ├── useOffline.ts            # Офлайн-режим
    ├── useLocalStorage.ts       # Работа с localStorage
    ├── useSessionStorage.ts     # Работа с sessionStorage
    ├── useDebounce.ts           # Debounce
    ├── useThrottle.ts           # Throttle
    ├── useClickOutside.ts       # Клик вне элемента
    ├── useMediaQuery.ts         # Медиа запросы
    ├── useIntersectionObserver.ts # Intersection Observer
    ├── useScroll.ts             # Управление скроллом
    ├── useCopyToClipboard.ts    # Копирование в буфер
    ├── useDownloadFile.ts       # Скачивание файлов
    ├── useFileUpload.ts         # Загрузка файлов
    ├── usePrint.ts              # Печать
    └── useGeolocation.ts        # Геолокация
```
