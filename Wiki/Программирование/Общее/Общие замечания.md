Реализация ожидания на формах, карточках и пр.

Главное правило:

- **Скелетон (Skeleton)** = **Чтение данных** (Мы ждем контент, чтобы показать его).
- **Блокировка/Спиннер (Loading State)** = **Запись данных/Действие** (Мы отправили команду и ждем подтверждения).

- **Скелетон** — для **загрузки** (GET запросы, инициализация).
- **Блокировка/Спиннер** — для **сохранения** (POST/PUT запросы, действия).
- **Никогда не заменяйте заполненную форму на скелетон во время отправки.** Это нарушает принцип сохранности контекста для пользователя.

### Матрица решений: Когда что использовать
| Сценарий                              | Что происходит?                                  | UI Паттерн                              | Почему?                                                                            |
| ------------------------------------- | ------------------------------------------------ | --------------------------------------- | ---------------------------------------------------------------------------------- |
| **Первичная загрузка страницы**       | Получение списка пациентов, дашборда, аналитики. | **Скелетон**                            | Пользователь ждет контент. Скелетон сохраняет верстку (CLS) и показывает прогресс. |
| **Отправка формы (Логин, Создание)**  | Мутация данных (POST/PUT).                       | **Блокировка + Спиннер**                | Структура известна. Главное — запретить повторную отправку и подтвердить действие. |
| **Загрузка конфигурации формы**       | Поля формы приходят с бэкенда динамически.       | **Скелетон формы**                      | Пользователь не знает, какие поля будут. Нужно скрыть отсутствие структуры.        |
| **Обновление части данных (Polling)** | Обновление статуса пациента в реальном времени.  | **Без скелетона** (или микро-индикатор) | Данные уже есть. Полное мерцание раздражает. Лучше подсветить изменившееся поле.   |
| **Бесконечный скролл**                | Подгрузка следующих страниц списка.              | **Скелетон внизу списка**               | Показывает, что контент еще есть и загружается.                                    |
| **Оффлайн-режим**                     | Попытка действия без сети.                       | **Блокировка + Тост "Нет сети"**        | Скелетон бессмысленен, так как запрос не уйдет. Нужно сразу сообщить о проблеме.   |

|Стиль иконки|Уровень важности|Где использовать в Hidden Hippo|
|---|---|---|
|**Duotone**|**Высокий (Primary)**|• Главные действия (Команды домена: «Синхронизировать», «Лицензировать»)  <br>• Активные пункты навигации  <br>• Статусы системы (Offline/Online)  <br>• Иконки в пустых состояниях (Empty States)|
|**Regular / Bold**|**Средний (Secondary)**|• Второстепенные действия (Редактирование, Фильтры)  <br>• Иконки внутри полей ввода (Input icons)  <br>• Карточки сущностей (Агрегаты)|
|**Thin / Light**|**Низкий (Tertiary)**|• Декоративные элементы  <br>• Фоновые паттерны  <br>• Disabled состояния (если не используется серый цвет)|
