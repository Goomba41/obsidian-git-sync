### Вводные данные
Требуется создать систему документирования кода внутри самого кода. Для этого будут использоваться комментарии и расширения [Highlight](https://marketplace.visualstudio.com/items?itemName=fabiospampinato.vscode-highlight) и [Todo+](https://marketplace.visualstudio.com/items?itemName=fabiospampinato.vscode-todo-plus) (оба от одного и того же автора Fabio Spampinato) для VSC. Изначально использовался Todo Tree как наиболее популярный, но случилась вынужденная (и надеюсь временная) замена на Todo+ (Highlight + Todo Tree не работают вместе по какой-то причине)

### Пояснения
**Принципы дизайна**
1. **Важность → Визуальный вес**: чем важнее, тем ярче/контрастнее
2. **Тип информации → Стиль**: предупреждения = жирный, пояснения = курсив
3. **Минимализм**: не более 2-3 стилей одновременно
4. **Согласованность**: одинаковые теги ведут себя одинаково во всех файлах

**Иерархия важности**

- **Красный/жирный** = «остановись и прочитай сейчас»
- **Оранжевый/жирный** = «запомни, нужно сделать»
- **Синий/курсив** = «интересно, но не срочно»
- **Зелёный/обычный** = «просто информация»

**Лаконичность**

- Всего **4 основных цвета** + 2 акцентных
- **3 типа стилей**: жирный, курсив, обычный
- **Минимальное использование фона** (только где действительно нужно)

**Группы комментариев по их назначению**

|Тег|Стиль|Цвет|Фон|Назначение|
