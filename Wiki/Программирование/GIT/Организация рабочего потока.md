Для проекта [[КСО]] возможный [вариант](https://app.diagrams.net/?client=1#LKSO_UNITED.drawio) репозитория.

![](../../../Pasted%20image%2020240206111028.png)

Хотелось бы сделать один объединенный репозиторий (монолит), так как смысла делить особо нет, все равно это единое приложение и вряд ли API (бэк) когда-то будет публичным. Еще несколько причин:
- Проще поддерживать в целом
- Не нужно бегать туда-сюда при создании issues, единая система на весь проект
- Напишем единую инструкцию по установке в вики проекта
- Для всех участников разработки доступен весь код для запуска полноценного приложения для разработки (сейчас, например, у Аркадия развернут у себя только бэк, и ему для тестов приходится пушить на стэнд)
- Удобнее вести версии приложения
- Результатом CI/CD будет являться единый архив с обеими частями, не нужно бегать туда-сюда для скачивания
- ? Раздельные права на ветки ?
