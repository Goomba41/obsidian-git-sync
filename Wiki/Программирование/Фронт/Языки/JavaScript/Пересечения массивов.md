### Пересечение

```javascript
let intersection = arr1.filter(x => arr2.includes(x));
```

[![Intersection Venn Diagram](https://i.stack.imgur.com/uasoX.png)](https://i.stack.imgur.com/uasoX.png)

Показывает значения из массивов `arr1` и `arr2`.

- `[1,2,3]` и `[2,3]` даст `[2,3]`
- `[1,2,3]` и `[2,3,5]`  _также_ даст `[2,3]`

---

### Разница

Значения только из подмножества А

```javascript
let difference = arr1.filter(x => !arr2.includes(x));
```

[![Right difference Venn Diagram](https://i.stack.imgur.com/mEtro.png)](https://i.stack.imgur.com/mEtro.png)

Даёт значения только из массива `arr1`.

- `[1,2,3]` и `[2,3]` дает `[1]`
- `[1,2,3]` и `[2,3,5]` _также_ дает `[1]`

---

### Симметричная разница

```javascript
let symDifference = arr1.filter(x => !arr2.includes(x))
                        .concat(arr2.filter(x => !arr1.includes(x)));
```

[![Symmetric difference Venn Diagram](https://i.stack.imgur.com/zb1hW.png)](https://i.stack.imgur.com/zb1hW.png)

Даёт значения _только_ из `arr1` или `arr2`, **но не из обоих** ("исключающее или").

Результат получен путем взятия разницы двух массивов друг с другом и последующей комбинацией этих результатов (будет получен массив из всех элементов массива `arr1`, которых нет в `arr2` и наоборот)

- `[1,2,3]` и `[2,3]` дает `[1]`
- `[1,2,3]` и `[2,3,5]` дает `[1,5]`

---

Также можно объявить эти функции напрямую в  `Array.prototype`, так что они могут быть использованы напрямую в массивах, например так:

```javascript
Array.prototype.diff = function(arr2) { 
  return this.filter(x => !arr2.includes(x)); 
}
```

```javascript
[1, 2, 3].diff([2, 3]) // [1]
```
